# 按钮规范与甘特图样式修复

## 按钮与返回入口

共享 `Button` 及 `buttonVariants` 统一主操作（青绿色）、普通描边、次要、无边框和危险操作（红色）。标准操作高度 40px，小尺寸与图标按钮保留独立规格。原生按钮共用基础字体、圆角、聚焦、禁用和按压反馈；明确的圆形图标与表格结构行保留自身形状。原有权限判断、事件和表单提交逻辑不变。

取消对所有 `<a>` 自动添加按钮边框和内边距的全局规则。普通链接保持链接语义，按钮式链接使用显式样式。此前行内返回链接的垂直内边距可能伸出行盒，与紧随的标题重叠。

`BackLink` 负责箭头图标与描边按钮，`PageBackLink` 额外提供块级容器和标题间距。项目子页面统一显示“返回任务看板”，任务看板返回项目列表时显示“返回项目看板”；文档原文返回项目文档。验收页返回入口移至顶部。项目成员、交付物、会议、文档、排期、需求追溯、设置、创建任务、WBS、风险、验收及导出均使用共享组件；审计、通知和任务独立详情也复用相同样式。

## 甘特图黑屏防护

黑色 SVG 网格、日期文字失去定位而堆到图表下方，符合图表节点存在但样式未应用的表现。甘特图原先在异步客户端组件中引入 CSS，现在将已限定 `.medpm-gantt` 范围的上游样式和应用覆盖样式移至根布局静态引入，避免图表 JavaScript 与样式走不同的延迟加载路径。

保留 Frappe MIT 版权说明。样式只影响图表容器，取消任务覆盖规则也补齐容器前缀。代价是应用外壳额外加载少量图表 CSS，换取首次进入与客户端导航时确定的样式可用性，不增加依赖。

图表初始化检查样式就绪标识。异常时展示已有只读任务列表，仍可打开只读任务详情，不呈现未应用样式的黑色 SVG。图表继续只读，不增加拖动保存或业务写入逻辑。

## 修改与验证位置

- `src/app/layout.tsx`、`globals.css`：稳定加载图表样式与全站按钮基础规范。
- `src/components/ui/button.tsx`、`page-back-link.tsx`：共享按钮变体及返回组件。
- `src/components/planning/planning-gantt.tsx`、`gantt-overrides.css`：样式检测与图表范围。
- 项目子页面、审计、通知、任务详情和验收组件：替换分散的返回样式。
- `e2e/gantt.spec.ts`：导航/刷新/日周月切换的真实计算样式断言、缺样式降级、依赖线和只读拖拽。
- `e2e/project-action-styles.spec.ts`：12 个项目子页面的按钮样式一致、返回目标与标题不重叠。
- 看板、交付物、项目设置、顶部导航及归档流程执行相关回归。

无数据库迁移、API 变更或新依赖。测试只使用隔离数据库与临时服务，不修改演示资料。
