# 任务看板布局

任务工作区只在列标题中展示待办、进行中、受阻、已完成数量，移除重复的顶部统计卡。阶段标题继续显示阶段内数量，已取消任务保留在底部默认折叠区。

头部左侧为最小 40px 点击高度的“返回项目看板”和项目名称，右侧集中放置 AI 结项体检、风险提交（符合既有条件时）及创建任务。返回地址继续使用服务端白名单解析的 returnTo，保留项目列表的关键词、状态、排序和页码。点击当前任务看板导航不会丢弃 URL 中的返回条件。

常用导航为任务看板、甘特图、交付物资产、会议纪要，使用选中态标明当前位置；其他项目功能收进“更多”。角色入口清单由 `src/modules/projects/navigation.ts` 统一提供，新看板和旧页面共享同一份权限展示规则。原有页面导航继续使用原样式与文案，链接目标及服务器鉴权不变。

“更多”使用按钮与菜单语义：支持方向键、Home/End、Escape、Tab 退出和外部点击关闭；打开后立即聚焦项目，避免异步聚焦抢走后续 Tab 焦点。窄屏的常用导航独立横向滚动，“更多”入口保持可见，菜单在内容区内展开，不放到被横向滚动容器裁剪的位置。

四列等高排列，列标题不随任务列表滚动，各列独立纵向滚动；窄屏保留任务列最小宽度并在看板内横向滚动，避免撑宽整个页面。阶段默认折叠规则、移动后展开高亮、抽屉、取消任务、电子签名、并发版本和 Capabilities 只读逻辑均不改动。

主要修改：

- `src/app/projects/[projectId]/board/task-board.tsx`：头部、统计去重、列与工具栏样式。
- `src/components/projects/project-board-navigation.tsx`：看板页签与可访问的更多菜单。
- `src/modules/projects/navigation.ts`、`src/components/project-navigation.tsx`：共享现有角色入口。
- `src/components/projects/acceptance-check-controls.tsx`：增加头部紧凑显示方式，业务判断不变。
- `e2e/board-layout.spec.ts`：菜单键盘操作、角色入口、返回地址、窄屏边界以及原有签名和折叠回归。
- 项目列表、维护、追溯、PM 流程测试更新新入口定位。测试截图默认关闭，按需显式采集。

没有数据库迁移、API 变更、新依赖或演示数据改写。测试通过独立数据库与临时测试服务执行。
