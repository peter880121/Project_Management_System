任务：设计并实现核心数据模型。

实体（MySQL）：
- User：id, email, name, role, createdAt
- Project：id, name, description, status, ownerId, createdAt
- Task：id, projectId, title, description, status, assigneeId, estimateHours, dueDate, createdAt
- Requirement：id, projectId, title, content, version, status, createdAt
- TestCase：id, requirementId, title, status, createdAt
- AuditLog：id, actorId, action, entityType, entityId, before, after, ip, userAgent, createdAt
- AiSuggestion：id, projectId, type, input, output, status, reviewedBy, reviewedAt, createdAt
- Document：id, projectId, filename, minioKey, parsedText, createdAt
- SyncFailure：id, entityType, entityId, target, payload, error, retryCount, createdAt

Milvus Collection：
- documents：id, docId, projectId, embedding, createdAt
  - 索引：HNSW，metric_type=COSINE
  - projectId 作为 scalar field，支持按项目过滤
  - embedding 维度 1536

要求：
- 使用 Prisma schema，provider 为 mysql。
- 主键统一 UUID，char(36)。
- 字符集 utf8mb4，引擎 InnoDB。
- 时间字段用 DATETIME(3)，存 UTC。
- 角色枚举：ADMIN, PM, MEMBER, QA。
- 任务状态枚举：TODO, IN_PROGRESS, DONE, BLOCKED。
- AiSuggestion 状态：PENDING, ACCEPTED, REJECTED。
- AiSuggestion 类型：WBS, ESTIMATE, RISK, AUDIT_SUMMARY。
- 创建 migration。
- 写一个 Milvus collection 初始化脚本，创建 documents collection 和 HNSW 索引。
- 写 seed 脚本，使用合成数据，包含至少 3 个项目、20 个任务、10 条审计日志。

验收：
- pnpm prisma migrate dev 成功。
- Milvus collection 创建成功，索引可用。
- seed 可重复执行。
- 不包含真实患者信息。

输出：计划、变更文件、迁移说明、测试结果、风险。
