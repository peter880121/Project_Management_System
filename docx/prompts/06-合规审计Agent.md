任务：实现合规审计追踪 Agent。

业务目标：
主动扫描项目数据，自动发现“需求-任务-测试”链路中的断裂点（如任务标记完成但关联测试未通过、需求变更未同步到任务等），生成人类可读的审计摘要，并标注引用的具体记录 ID。仅 ADMIN 和 QA 可使用。

技术要求：
- 输入：某项目一段时间内的 AuditLog、Task、Requirement、TestCase 数据。
- 输出：结构化摘要，突出异常、关键变更、待复查项。
- 摘要必须标注引用的审计记录 ID。
- 摘要本身也写入审计日志。
- LLM 失败时返回原始审计列表，不阻塞。
- 权限校验：仅 ADMIN 和 QA 可访问。
- 支持按时间范围、项目、操作人筛选。
- 前端展示摘要，点击引用 ID 可跳转到对应审计记录。

验收标准：
- 摘要可追溯。
- 权限正确。
- 测试覆盖权限、失败降级、审计记录。
- 提供 API 和前端页面。
- 生成的摘要本身也被记录为审计事件。

输出：计划、变更文件、测试结果、风险。
