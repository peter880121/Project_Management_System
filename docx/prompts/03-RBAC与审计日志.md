任务：实现 RBAC 和审计日志基础能力。

要求：
- 实现 requireRole(user, roles) 工具。
- 所有 API 路由必须校验权限。
- 实现 recordAudit() 服务，支持事务内写入。
- 以下操作必须写审计：
  - 任务状态变更
  - 任务分配
  - 权限变更
  - 数据导出
  - AI 建议采纳/拒绝
  - RAG 检索（记录 query、命中 ID、耗时、是否降级）
- 提供 GET /api/audit?projectId=...，仅 ADMIN 和 QA 可访问。
- 审计日志不可删除、不可修改。
- 提供审计日志查询的前端页面，支持按项目、时间、操作人筛选。

测试：
- 无权限访问返回 403。
- 任务状态变更后审计记录存在且字段完整。
- 审计日志查询按项目过滤。
- AI 建议采纳后审计记录包含建议 ID 和采纳人。

输出：计划、变更文件、迁移、测试结果、风险。
