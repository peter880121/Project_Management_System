任务：初始化 MedPM-AI 项目骨架。

项目定位：
医疗软件交付 AI 平台，核心是三个 AI Agent：智能 WBS 分解与工期预估、合规审计追踪、资源冲突与风险预警。

要求：
- 使用 Next.js 15 App Router + TypeScript + Tailwind + shadcn/ui。
- 集成 Prisma + MySQL 8。
- 集成 Milvus 客户端（@zilliz/milvus2-sdk-node）。
- 配置 pnpm、ESLint、Prettier、Vitest。
- 创建基础目录：
  - src/app
  - src/modules/auth
  - src/modules/projects
  - src/modules/tasks
  - src/modules/audit
  - src/modules/ai
  - src/modules/vector（Milvus 封装）
  - src/modules/documents（MinIO + MinerU 集成）
  - src/lib
- 提供 Docker Compose：app + mysql + milvus + etcd + minio + redis（可选）。
- MySQL 使用 utf8mb4，配置持久化 volume。
- Milvus standalone 依赖 etcd 和 MinIO，MinIO 与业务共用同一实例。
- 提供 .env.example，不写真实密钥。
- 写一个健康检查接口 /api/health，返回 MySQL、Milvus、MinIO 连通状态。
- 写一个 README.md，说明项目定位、技术栈、本地启动步骤。

输出：
1. 执行计划
2. 变更文件列表
3. 启动命令
4. 验证方式
5. 下一步建议
